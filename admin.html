Чтобы менять сайт, нужен ключ доступа к вашему репозиторию на GitHub. Его создают один раз на каждом устройстве.

  1. Откройте создание ключа на GitHub. Название и права уже заполнены.
  2. В «Repository access» выберите Only select repositories и отметьте akkumulyatory-kazani.
  3. Внизу нажмите Generate token и скопируйте ключ. Он начинается с github_pat_.
  4. Вставьте ключ ниже.

Ключ хранится только в этом браузере. Никому его не пересылайте. Если устройство потеряли, удалите ключ на GitHub: Settings → Developer settings → Personal access tokens.
