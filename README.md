# Аккумуляторы Усады

Сайт магазина аккумуляторов в Усадах (Лаишевский район): подбор аккумулятора, выезд и прикурка, приём старых аккумуляторов со скидкой на новый, связь с менеджером через WhatsApp, Telegram, MAX и звонок.

Весь сайт — один файл `index.html`, без сборки и внешних библиотек. Публикуется через GitHub Pages.

## Как поменять телефон, мессенджеры, адрес и часы работы

Откройте `index.html`, найдите блок `НАСТРОЙКИ САЙТА` в начале скрипта (внизу файла) и поменяйте значения:

| Поле | Что это |
|---|---|
| `phoneDisplay` | номер так, как его видят посетители |
| `phone` | номер для звонка, в формате `+7…` |
| `whatsapp` | номер для WhatsApp, только цифры: `79377745444` |
| `telegram` | ник в Telegram без `@` или номер с `+` |
| `max` | ссылка на профиль в MAX: в приложении «Профиль → Пригласить друзей → Скопировать ссылку» |
| `hours`, `hoursLabel` | часы работы для отметки «сейчас работаем» и их подпись |
| `addressShort`, `addressRegion`, `addressFull`, `mapQuery` | адрес и запрос для Яндекс Карт и 2ГИС |
| `endpoint` | адрес обработчика заявок, если подключите приём сообщений из чата на сайте |

Пока `endpoint` пустой, чат на сайте готовит сообщение и предлагает отправить его в WhatsApp, Telegram, MAX или позвонить.

Номер также записан прямо в разметке страницы (на случай, если скрипт не загрузится). При смене номера замените его поиском по файлу: `+7 937 774-54-44`, `+79377745444` и `79377745444`.

## Публикация

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. После каждого изменения сайт обновляется сам примерно за минуту.
